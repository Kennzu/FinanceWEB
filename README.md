# FinanceWEB
Начальный этап разработки сайта для общих проектов

# Главная страница
Создана **главная** страница, на которую пользователь будет попадать при переходе по ссылке.

# Общая страница с проектами
Создана **общая** страница с проектами, где будут собраны все проекты

# Страницы проектов
Созданы отдельные страницы проектов и под них сделаны страницы с документацией на каждый программный продукт

# Улучшения
Добавлена адаптивная верстка на каждую из страниц под множество разрешений
